# Олимпиадник

Сервис подготовки к перечневым олимпиадам по физике и математике: программа
обучения, конспекты, задачи, сборники и навигатор поступления по олимпиадным льготам.

Сайт: [po-bvi.ru](http://po-bvi.ru/).

## Возможности

- Программа по физике и математике с темами и подтемами.
- Короткие конспекты и большие интерактивные материалы.
- Задачи по темам с отметками «Решена» и «Есть вопросы».
- Сборники по физике и математике: оглавление, поиск, условия, раскрывающиеся
  решения и рисунки. Математические материалы отображаются нативно в HTML,
  с KaTeX/MathML и SVG-чертежами.
- Архив олимпиадных заданий.
- Навигатор «БВИ и вузы» с правилами льгот и структурированными датами этапов.
- Личный прогресс и рекомендации, что продолжить.
- Интерфейс помощника для разбора задач. Ответы пока статические;
  подключение языковой модели ещё не реализовано.

Сборники и полные конспекты требуют входа. Прогресс сохраняется для
авторизованных пользователей. Подписка и платный доступ не являются
текущим пользовательским сценарием сайта.

## Стек и архитектура

| Часть | Технологии |
| --- | --- |
| Фронтенд | React 18, Vite 5, Tailwind CSS 3 |
| Интерфейс | Собственные компоненты, Framer Motion |
| Математическая вёрстка | KaTeX, MathML, SVG |
| Бэкенд | FastAPI, Pydantic, SQLAlchemy 2 с asyncpg |
| База данных | PostgreSQL; Neon для разработки, локальный PostgreSQL на VPS в проде |
| Миграции | Alembic |
| Авторизация | JWT |
| Прод | Ubuntu, nginx, Uvicorn под systemd, GitHub Actions |

Фронтенд собирается в статические файлы, но получает контент и прогресс
через API. Это не автономный HTML-макет: для работы разделов нужен бэкенд.
В проде nginx отдаёт фронтенд и проксирует `/api/` на FastAPI.

## Локальный запуск

Нужны Node.js с npm, Python и доступ к PostgreSQL. Для соответствия текущему
Deploy используется Node.js 22. Команды ниже — для Windows PowerShell.

### 1. Бэкенд

Из корня репозитория:

```powershell
cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Укажи в `backend/.env` свои параметры подключения. Пример для локального PostgreSQL:

```dotenv
DATABASE_URL=postgresql+asyncpg://user:password@127.0.0.1:5432/bvi
DATABASE_SSL=disable
JWT_SECRET=replace-with-a-long-random-string
CORS_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

Для Neon используй свою строку подключения и `DATABASE_SSL=require`.
Настоящие пароли и ключи в Git не добавляются.

Применить миграции, загрузить основной контент и запустить API:

```powershell
python -m alembic upgrade head
python -m scripts.seed
python -m uvicorn app.main:app --reload --port 8000
```

Документация API: [localhost:8000/docs](http://localhost:8000/docs).
Дополнительные сведения о бэкенде — в [backend/README.md](backend/README.md).

### 2. Фронтенд

В отдельном терминале, из корня репозитория:

```powershell
npm ci
npm run dev
```

Сайт: [localhost:5173](http://localhost:5173).
По умолчанию API доступен по `http://localhost:8000/api`.
Для другого адреса задай `VITE_API_URL` в корневом `.env.local`.
В проде используется **`VITE_API_URL=/api`**.

Vite подставляет переменную при сборке: после изменения её значения
продакшен-фронтенд нужно пересобрать.

## Разделы сайта

Используется собственный хэш-роутер в `src/App.jsx`.

| Маршрут | Раздел |
| --- | --- |
| `#/` | Главная |
| `#/program` | Темы и программа подготовки |
| `#/theory/<lesson-id>` | Короткий конспект подтемы |
| `#/conspect/math` / `#/conspect/physics` | Оглавление больших конспектов |
| `#/catalog` | Задачи по темам |
| `#/topic/<id>` | Теория темы, задачи и панель помощника |
| `#/collections?subject=physics` | Сборники по физике |
| `#/collections?subject=math` | Сборники по математике |
| `#/collections/<book>/<chapter>` | Раздел сборника |
| `#/bvi` | БВИ и вузы |
| `#/archive` | Архив олимпиадных заданий |
| `#/tiktok` | Раздел «Из тиктока» |
| `#/progress` | Мой прогресс |
| `#/login` | Вход и регистрация |

## Контент и структура репозитория

- `src/` — страницы, компоненты, хэш-роутер и клиент API.
- `src/data/` — презентационные константы, а не база учебного контента.
- `backend/app/` — API, модели и логика работы с данными.
- `backend/alembic/` — миграции схемы PostgreSQL.
- `backend/scripts/` — сиды, загрузчики конспектов и сборников, обработка материалов.
- `conspects/` — исходники и инструменты сборки конспектов.
- `.github/workflows/` — деплой и проверка обновлений дат олимпиад.
- `AGENTS.md` и `CLAUDE.md` — договорённости команды, архитектурные нюансы
  и подробные инструкции по эксплуатации.

Основной контент загружается командой `python -m scripts.seed`.
Большие материалы и сборники используют отдельные загрузчики. Приватные архивы
не входят в Git, поэтому обычного клонирования и сида недостаточно для
получения всей библиотеки материалов. Порядок импорта описан в инструкциях команды.

## Проверки и сборка

```powershell
# Из корня: сборка фронтенда
npm run build

# Из backend, с активированным окружением и настроенной dev-базой
python -m pytest -q
```

Сборка фронтенда попадает в `dist/`. Для просмотра сборки через HTTP:

```powershell
npm run preview
```

Бэкенд при этом должен быть доступен по адресу, указанному при сборке.
Тесты бэкенда требуют настроенной тестовой/dev-базы; не направляй их на прод.

## Деплой

Деплой запускается вручную: **GitHub → Actions → Deploy → Run workflow → main**.
Перед запуском изменения должны быть закоммичены и запушены в `main`.

Workflow собирает фронтенд, публикует релиз, обновляет код бэкенда,
устанавливает зависимости, применяет миграции и перезапускает сервисы.
На VPS фронтенд отдаётся через симлинк `current` на каталог релиза.

Изменения сидов требуют отдельного запуска сида на сервере.
Изменения приватных сборников требуют передачи свежего архива и повторного
импорта. Обычный Deploy не заменяет эти шаги. Отдельные материалы, подключённые
в workflow, загружаются его собственными шагами.

Полный чек-лист, настройки сервера и команды импорта:
[AGENTS.md](AGENTS.md) и [CLAUDE.md](CLAUDE.md).

## Дизайн

Тема «тетрадь и чертёж»: тёплая бумага, чернильно-синий `pen`, красный акцент
`mark`, янтарные статусы. Заголовки — Fraunces, основной текст — Manrope,
числовые метки — IBM Plex Mono. Общие стили находятся в `src/index.css`,
компоненты — в `src/components/ui.jsx`. Анимация учитывает системную
настройку уменьшения движения.
