# «Без Вступительных» — кликабельный прототип

Визуальный макет образовательного сервиса подготовки к перечневым олимпиадам по физике и
математике. Тэглайн: **«База вузов — получи своё БВИ в вуз мечты»**.

Раньше это был чисто фронтенд-прототип без бэкенда — теперь контент (темы, задачи, олимпиады,
вузы, тарифы) и прогресс пользователя обслуживает реальный API на FastAPI, см.
[backend/README.md](backend/README.md). Оплата и ИИ-помощник по-прежнему не подключены (мок на
фронтенде).

## Запуск

Сначала — бэкенд (иначе каталог/тема/база/кабинет не загрузятся, увидите сообщение об ошибке
вместо контента): следуйте [backend/README.md](backend/README.md) — поднять БД, `alembic
upgrade head`, `python -m scripts.seed`, `uvicorn app.main:app --reload --port 8000`.

Затем фронтенд:

```bash
npm install
npm run dev
```

По умолчанию фронтенд ходит на `http://localhost:8000/api` — при необходимости переопределите
через `VITE_API_URL` в `.env` (см. `.env.example`).

Дальше открыть адрес, который напечатает Vite (по умолчанию `http://localhost:5173`).

Сборка статики: `npm run build` (кладётся в `dist/`, `base: './'` — открывается и с файловой
системы, и с любого статического хостинга).

## Экраны

Навигация — по хэшу, без роутер-библиотеки.

| Маршрут | Экран |
| --- | --- |
| `#/` | Лендинг: хиро, «для кого», «как это работает», примеры олимпиад и вузов, ИИ-помощник, тарифы |
| `#/catalog` | Каталог тем: фильтр по предмету, поиск, группировка по разделам |
| `#/topic/<id>` | Страница темы: конспект теории + задачи трёх уровней + ИИ-помощник |
| `#/progress` | Личный кабинет (требует входа): прогресс по темам и предметам, «продолжить», слабые места |
| `#/base` | База олимпиад и вузов с льготами (открытый раздел) |
| `#/login` | Вход и регистрация |

Быстрый маршрут для демонстрации сценария:
`#/` → «Начать подготовку» → `#/catalog` → тема → `#/login` (регистрация) → `#/progress`.

### Что можно потыкать

- Фильтры «Все предметы / Физика / Математика» и поиск в каталоге.
- Раскрытие подсказки у каждой задачи.
- Платные темы — средний и сложный уровни закрыты пейволом (`btn-primary` «Смотреть тарифы»)
  для всех, кроме подписчиков; проверка теперь серверная, а не клиентская.
- Кнопки-подсказки у ИИ-помощника на странице темы (ответы заранее заготовлены, наружу ничего
  не уходит).
- Вкладки «Олимпиады / Вузы и льготы» в базе, фильтры по статусу в кабинете.

## Данные

Контент (разделы, темы, задачи, олимпиады, вузы, тарифы) и прогресс пользователя отдаёт
бэкенд — см. [backend/README.md](backend/README.md) и [backend/scripts/seed_data.py](backend/scripts/seed_data.py)
(8 разделов, 25 тем, 150 задач, 5 олимпиад, 6 вузов, 2 тарифа). В `src/data/` остались только
презентационные константы без бэкенд-аналога: `topics.js` — тайлвинд-классы уровней сложности,
`site.js` — маркетинговый копирайт лендинга и статусные цвета кабинета.

Формулировки задач — реалистичные, но демонстрационные: привязка к конкретным этапам олимпиад
условна и нужна только для макета. То же касается данных о льготах и проходных баллах.

## Палитра и типографика

Академическая, а не «кислотный EdTech»: тёплая бумага `#FBFAF8`, глубокий хвойный
`#1D473B` как основной акцент, терракота `#BB5E3B` для второстепенных акцентов, янтарный для
среднего уровня сложности. Градиентов и мультяшных иконок нет: фон хиро — тонкая
«миллиметровка», иконки — линейные SVG в `src/components/ui.jsx`.

Шрифт — Manrope (Google Fonts) с системным фолбэком; без интернета вёрстка не ломается.

## Стек

Vite 5 + React 18 + TailwindCSS 3. Внешних UI-библиотек нет.
